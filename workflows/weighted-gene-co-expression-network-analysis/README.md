# Weighted Gene Co-expression Network Analysis (WGCNA)

A methods-only overview of expression-network construction, module detection,
module-trait associations and network export.

The analytical structure connects quality-reviewed expression to a declared
network definition, topological-overlap modules, eigengene summaries and
gene-level measures. Module membership, trait association and network
connectivity remain distinct quantities; co-expression does not establish a
regulatory mechanism.

[Methods](METHODS.md) describes the input requirements, analytical choices and
interpretation limits. This entry contains no executable pipeline, research
data, sample metadata, module assignments or biological results. It is not a
study-reproduction package and does not prescribe universal parameter values.
